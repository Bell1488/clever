# НЕРИДА — готовая сборка сайта

Здесь самостоятельная версия сайта с сервером заявок. Нужны Node.js 22.13 или новее, системный `curl` в PATH и актуальные корневые сертификаты. Сборка уже готова: npm, Docker и установка JS-зависимостей для запуска не нужны.

## Запуск для проверки

1. Скопируйте `env.example` в `.env`.
2. Заполните параметры Telegram-бота и SOCKS5h-прокси.
3. Выполните в этой папке:

```bash
node --env-file=.env server.mjs
```

По умолчанию сайт доступен на `http://127.0.0.1:3000`. Приватного режима и переключателя индексации нет. На сервере настройте HTTPS через Nginx/Caddy и проксирование на этот локальный порт. Пример Nginx есть в общем архиве `docs/nginx.conf`.

Проверка Telegram без отправки сообщений и без запуска HTTP-сервера:

```bash
node --env-file=.env server.mjs --check-telegram
```

Команда проверяет SOCKS5h, TLS, токен, доступ к чату и права бота в группе/канале. При ошибке выводит код и подсказку без секретов. Подробности — `docs/TELEGRAM.md` в корне репозитория.

## Куда приходят заявки

Форма отправляет заявку прямо в указанную Telegram-группу через SOCKS5h после настройки `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `TELEGRAM_PROXY_URL`. Административной панели на сайте нет. При ошибке Telegram или прокси посетитель видит понятное сообщение и может повторить отправку.

## Перед рекламой

- Укажите окончательный `SITE_URL` с HTTPS. Счётчик Метрики `114601476`, Telegram https://t.me/nerida_obmen и контакты закреплены в коде; `METRIKA_ID` задавать не нужно.
- Создайте цели в своём счётчике по `docs/METRIKA.md` из корня архива и привяжите его к Директу.
- Платёжный калькулятор использует фиксированный курс 12.79 RUB/CNY. Тарифы и сроки карго остаются предварительными и требуют подтверждения.
- Проверьте хранение заявок, приём обращений и данные документов для выбранного сервера. Настройте резервирование и сроки удаления. Для рекламной копии выберите подходящее размещение данных и подтвердите условия их обработки.
- Сайт всегда открыт для индексации. Дополнительный переключатель публикации не нужен.
- Отправьте тестовую заявку и проверьте её получение в Telegram, а событие `lead_success` — в вашем счётчике.

Включены главная, карго, блог с шестью статьями, контакты и юридические документы. Страницы содержат HTML-текст для индексирования. Robots.txt всегда разрешает основные страницы и исключает служебный API. Sitemap использует `SITE_URL`; без домена он недоступен, но индексация страниц не блокируется.

Не размещайте `.env`, серверный код и каталог данных внутри чужого public_html. Для готовой сборки нужен Node.js-хостинг/VPS, а не только статический или PHP-хостинг.
