# Клевер — готовая сборка сайта

Здесь самостоятельная версия сайта с сервером заявок. Нужен Node.js 22.13 или новее. Сборка уже готова: npm, Docker и установка зависимостей для запуска не нужны.

## Запуск для проверки

1. Скопируйте `env.example` в `.env`.
2. Заполните параметры Telegram-бота и SOCKS5h-прокси.
3. Выполните в этой папке:

```bash
node --env-file=.env server.mjs
```

По умолчанию сайт доступен на `http://127.0.0.1:3000` и остаётся в режиме проверки. На сервере настройте HTTPS через Nginx/Caddy и проксирование на этот локальный порт. Пример Nginx есть в общем архиве `docs/nginx.conf`.

## Куда приходят заявки

Форма отправляет заявку прямо в указанную Telegram-группу через SOCKS5h после настройки `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `TELEGRAM_PROXY_URL`. Административной панели на сайте нет. При ошибке Telegram или прокси посетитель видит понятное сообщение и может повторить отправку.

## Перед рекламой

- Укажите окончательный `SITE_URL` с HTTPS, номер `METRIKA_ID`, ссылку `TELEGRAM_URL`, телефон `CONTACT_PHONE` и почту `CONTACT_EMAIL`.
- Создайте цели в своём счётчике по `docs/METRIKA.md` из корня архива и привяжите его к Директу.
- Платёжный калькулятор использует фиксированный курс 12.79 RUB/CNY. Тарифы и сроки карго остаются предварительными и требуют подтверждения.
- Проверьте хранение заявок, приём обращений и данные документов для выбранного сервера. Настройте резервирование и сроки удаления. Для рекламной копии выберите подходящее размещение данных и подтвердите условия их обработки.
- После выполнения этих шагов задайте `PUBLIC_LAUNCH=true`, чтобы открыть индексацию. Переключатель не зависит от Метрики, контактов или доставки Telegram.
- Отправьте тестовую заявку и проверьте её получение в Telegram, а событие `lead_success` — в вашем счётчике.

Включены главная, карго, блог с шестью статьями, контакты и юридические документы. Страницы содержат HTML-текст для индексирования. При `PUBLIC_LAUNCH=false` сервер отдаёт noindex и запрещающий robots.txt. После включения запуска robots.txt разрешает основные страницы и исключает служебные. Sitemap использует `SITE_URL`.

Не размещайте `.env`, серверный код и каталог данных внутри чужого public_html. Для готовой сборки нужен Node.js-хостинг/VPS, а не только статический или PHP-хостинг.
