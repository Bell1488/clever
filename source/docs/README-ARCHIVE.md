# Клевер — сайт платежей и доставки из Китая

- `site/` — готовый самостоятельный сайт и сервер приёма заявок. Запускается на Node.js 22.13+ без установки зависимостей и Docker. Начните с `site/README.md`.
- `source/` — полные исходники, калькуляторы, статьи, формы, схема данных и скрипт повторной сборки `portable/build.mjs`. Для разработки установите зависимости через pnpm указанной в package.json версии.
- `docs/TELEGRAM.md` — подключение заявок в Telegram строго через SOCKS5h.
- `docs/METRIKA.md` — список целей, подключение Метрики, UTM и проверка конверсий.
- `docs/nginx.conf` — пример обратного прокси.
